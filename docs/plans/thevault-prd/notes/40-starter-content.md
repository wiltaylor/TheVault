# Starter content

## Question
Q37: Ship example content?

## Answer
`vault init --starter` adds Task, Project, Person and Note types, a Status taxonomy and one dashboard note with kanban and calendar views. A plain `vault init` creates an empty vault.

## Why
Doubles as test data and as the agent skill document's demo, and stays opt-in.

## Consequences
None.
