## Default Permission

Lets the webview open the capture setup screen, read the capture status and capture health and open the screens that fix it, import the phone's history, check for new messages and calls, and read and run the app update check.

#### This default permission set includes the following:

- `allow-open-capture-setup`
- `allow-capture-status`
- `allow-capture-health`
- `allow-open-capture-fix`
- `allow-import-history`
- `allow-import-status`
- `allow-check-now`
- `allow-update-status`
- `allow-check-for-updates`
