# Release scope

## Question
Q1: What ships in the first usable release?

## Answer
Everything in the destination ships in one release. No phased scope.

## Why
User chose option 2 over the recommended three-phase plan.

## Consequences
The PRD carries no phase boundaries, so it must still give a build order or dependency notes so implementation can sequence work. Scope risk is high and is flagged in the PRD risks section.
