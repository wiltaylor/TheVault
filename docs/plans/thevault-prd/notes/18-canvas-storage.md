# Canvas storage

## Question
Q18: How are canvases stored?

## Answer
A native WCL canvas schema designed for TheVault, not JSON Canvas.

## Why
User chose option 2 over the recommended extended JSON Canvas.

## Consequences
Obsidian interoperability is not free. Whether to offer JSON Canvas import/export is open (Q25).
