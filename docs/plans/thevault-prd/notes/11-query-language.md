# Query language

## Question
Q11: Text DSL, visual builder, or both?

## Answer
A text query language plus a visual builder that edits it. The same language is used in blocks, API, CLI and wscript.

## Why
Agents need text. The UI must stay WYSIWYG. One language means agent-written queries render in blocks.

## Consequences
The syntax basis is undecided (Q26).
